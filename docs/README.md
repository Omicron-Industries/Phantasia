# Phantasia Documentation

Phantasia is a visual documentation and teaching tool for modpacks — interactive 3D machine previews, step-by-step assembly walkthroughs, multi-machine scene layouts, and rich text guides, all in-game.

How to open Phantasia, navigate the browser, use the 3D viewer, follow walkthroughs, and change settings.

## Quick Links

- Open the browser in-game: `/phantasia`
- Hold `[P]` near any machine to open its viewer directly
- Creative-mode editing: find any content card in the browser → click **✏ Edit**
- Theme editor: `/phantasia` → Settings → **🎨 Open Theme Editor**
