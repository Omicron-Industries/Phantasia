# Phantasia: Scene Builder Reference

Phantasia lets you build, preview, and share scripted 3D scenes and guided tutorials.

## Tutorials
Phantasia has a built-in tutorials tab for a visual representation of the information shown in this wiki.

## Scenes

- Create a scene from the Scene Selection screen, then place blocks and add script steps.
- Preview a scene at any time to see it exactly as players will.
- The floor block under previews (the "baseplate") can be changed per-theme from Settings.

## Guides

Guides are step-by-step in-game tutorials you write and attach to scenes. See the Guide Editor
to build one.

## Theme

Phantasia shares its color theme with every other Phoenix mod installed. Use **Open Theme
Editor** in Settings to customize it, and it applies everywhere at once.

## Web Export

Export a dimension's scenes to a browsable web map from Settings → Web Export. Currently under dev.
